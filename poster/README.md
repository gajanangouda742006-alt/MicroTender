# MicroTender Poster

Files:

- `microtender-poster.html` - editable poster layout
- `poster.css` - poster styling
- `assets/ERdiagramofdbms.png` - ER diagram used in the poster

How to use:

1. Open `microtender-poster.html` in a browser.
2. Edit placeholder details such as team members, guide name, and institution.
3. Use browser print and choose `Save as PDF`.
4. Select portrait layout and keep background graphics enabled for best output.

Suggested last edits:

- Add your college logo if needed.
- Replace placeholder names in the top information cards.
- Add project repository link or QR code if your faculty asks for it.
